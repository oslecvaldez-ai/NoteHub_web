# Comandos directos para el proyecto web

| Comando                    | Qué exporta / genera                                     |
| :------------------------- | :------------------------------------------------------- |
| `npm run export:core`      | Genera `CONSOLIDADO_src_core.txt`                        |
| `npm run export:notas`     | Genera `CONSOLIDADO_src_modules_notas.txt`               |
| `npm run export:editor`    | Genera `CONSOLIDADO_src_modules_editor.txt`              |
| `npm run export:espacios`  | Genera `CONSOLIDADO_src_modules_espacios.txt`            |
| `npm run export:papelera`  | Genera `CONSOLIDADO_src_modules_papelera-plantillas.txt` |
| `npm run export:respaldos` | Genera `CONSOLIDADO_src_modules_respaldos.txt`           |
| `npm run export:config`    | Genera `CONSOLIDADO_src_modules_configuracion.txt`       |
| `npm run export:electron`  | Genera `CONSOLIDADO_electron_main.txt`                   |
| `npm run tree`             | Muestra la estructura de carpetas limpia en consola      |
