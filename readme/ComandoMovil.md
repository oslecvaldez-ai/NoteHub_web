# Comandos directos para el proyecto móvil

| Comando                     | Qué exporta / genera                                 |
| :-------------------------- | :--------------------------------------------------- |
| `npm run export:core`       | Genera `CONSOLIDADO_core.txt`                        |
| `npm run export:navigation` | Genera `CONSOLIDADO_navigation.txt`                  |
| `npm run export:cuadernos`  | Genera `CONSOLIDADO_modules_cuadernos-notas.txt`     |
| `npm run export:editor`     | Genera `CONSOLIDADO_modules_editor.txt`              |
| `npm run export:espacios`   | Genera `CONSOLIDADO_modules_espacios.txt`            |
| `npm run export:papelera`   | Genera `CONSOLIDADO_modules_papelera-plantillas.txt` |
| `npm run export:respaldos`  | Genera `CONSOLIDADO_modules_respaldos.txt`           |
| `npm run export:config`     | Genera `CONSOLIDADO_modules_configuracion.txt`       |
| `npm run tree`              | Muestra la estructura de carpetas en consola         |
